# Планер

Личный планер: календарь, задачи, финансы (наличные и карта, долги), кредиты с планом погашения, цели, привычки и заметки. Работает на iPhone (как приложение с экрана «Домой») и на Mac (отдельная программа), данные синхронизируются через Supabase.

## Устройство репозитория

| Путь | Что это |
|---|---|
| `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` | Версия для iPhone и браузера (публикуется через GitHub Pages) |
| `src/app.js`, `src/views-money.js`, `src/calc.js`, `src/styles.css` | Общий код и оформление — одинаковые на iPhone и Mac |
| `src/sync.js`, `src/sync.css` | Синхронизация и вход в аккаунт |
| `src/web.js`, `src/web.css` | Только для iPhone: нижняя панель, меню «Ещё», загрузка из файла |
| `config.js` | Адрес проекта Supabase и публичный ключ |
| `supabase/schema.sql` | Таблица и правила доступа для базы |
| `mac/` | Программа для Mac (Electron): `bash mac/build.sh` собирает `Planer.app` |
| `vendor/` | Библиотека Supabase (MIT) |

## Где хранятся данные

В репозитории только код. Записи хранятся в базе Supabase в таблице `planner_docs`; правила базы (row level security) дают каждому пользователю доступ только к своим строкам после входа. Ключ в `config.js` — публичный «anon»-ключ, он рассчитан на размещение в открытом коде.

На каждом устройстве есть копия данных, поэтому планер работает и без интернета; изменения отправятся в облако при появлении связи. Если одну и ту же часть (например, задачи) поменять на двух устройствах без интернета, сохранится последняя отправленная версия.
